Nine agents, one board, and the hooks that keep them honest.

A fleet of Claude Code subagents with narrow, enforced roles. Each does a single job and reports in a fixed format. None grades its own work.

The interesting part is not the prompts. It is the machinery around them: a scope hook that denies calls a role forbids, a board that moves only on evidence, and a test suite that fails when a run fails.
